# ⚔️ Murim Clash

A browser-based Rock-Paper-Scissors game inspired by martial arts (Murim) novels.

Instead of the traditional Rock, Paper, and Scissors, players battle using unique martial arts techniques with a themed interface and custom artwork.

## 🎮 Live Demo

🔗 [https://your-live-link-here](https://chaitanya-sakamuri.github.io/rock-paper-scissors/)

## ✨ Features

- ⚔️ Murim-themed gameplay
- 🎨 Custom UI and artwork
- 📱 Responsive design
- 🏆 Score tracking
- 🎲 Random AI opponent
- ⚡ Instant game results

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
